# EduContinuum 🎓

> A lightweight frontend e-learning platform for students during temporary school disruptions and lockdowns.

## 📌 About

EduContinuum is a simple e-learning platform designed to help students continue learning when normal school activities are temporarily disrupted.

## ✨ Features

- Student information form
- Student dashboard
- Subject cards
- Teacher directory with 12 sample teachers
- Learning resources
- Completed subjects and progress
- Responsive design for different devices

## 📚 Subjects

## 🛠️ Technologies

- HTML5 — Structure
- CSS3 — Styling and responsive design
- JavaScript — Minimal interactivity
- Local Storage — Temporary data storage
- VS Code — Development
